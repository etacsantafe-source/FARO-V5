## B1 — Brecha comprobada
AuxiliaryPortabilitySnapshot, AuxiliaryPortabilityProjection y readPortabilitySnapshot solo proyectan Avisos. PortabilityCore enumera cinco secciones; PortabilitySourceReader lee únicamente scope aprobado. PortableBundleJsonWriter genera JSON con digests y manifiesto NOT RESTORABLE. Aceptación: sección BOOKMARKS explícita, referencias y carpetas sin texto, token, digest de autoridad, receipts ni keys; gate live antes/después; preview invalidado por cambios de metadata; no fallback vacío si falta owner.

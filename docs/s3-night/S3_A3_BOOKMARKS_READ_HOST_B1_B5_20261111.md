## B4 — Unified exact implementation scope
Auxiliary method creates a read-only closure on its current connection/lock; wrap gate to delegate scope/target only, preserve isMutationActive=false, expose no mutation interface. Host binding requires full pointer, host epoch/foreground and independent BOOKMARK_METADATA + WORKSPACE_MESSAGE grant epochs. Pin both epochs and owner token/revision around read; Workspace gate validates each target; catch owner unavailability safely and preserve coroutine cancellation. Return DTO of exact opaque IDs/favorite/folder metadata, no Workspace token, source text/title, authority digest, tombstones or receipts. Bound first page50 and explicit hasMore. Null means unavailable, authorized empty means no saved items. Closed binding/owner and stale pointer deny.
Native DEV-only dedicated Guardados button extends existing explicit-request state and opens trusted Application sandbox policy. It grants only the two read domains, then invokes new binding on worker. Final UI publish requires same session, same binding, foreground, unchanged grant epochs and pointer/host. onPause clears pending click, redacts view, closes binding/authority; resume does not restore old grant. UI says metadata references only and bounded result, never global total. No native Save/Apply or exact source navigation in this unit; those require next independently reviewed mutation/navigation unit.

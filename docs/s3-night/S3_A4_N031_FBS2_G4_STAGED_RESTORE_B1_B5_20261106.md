- restic design (https://github.com/restic/restic/blob/master/doc/design.rst): referencias inmutables/orden duradero para tolerancia a interrupciones. ADAPTAR pin de identidad antes de escribir, comprobar igualdad exacta en cada reintento. DESCARTAR importar restic/creación de otro repositorio.

- Se compararon 2 alternativas de coordinación local (mutar el legacy vs añadir restaurador interno stage-only) y al menos 2 implementaciones externas (restic/Joplin), sin dependencias ni API de pago.

## B3 — Alternativas externas verificadas
Consultadas 2026-11-10:
- SQLite Online Backup API https://www.sqlite.org/backup.html: copia consistente de una DB frente a copia cruda susceptible a corrupción. Alternativa física DESCARTADA aquí: no coordina cinco owners ni filtra DeliveryIntent Clase D. SQLite existente, dominio público, sin nueva dependencia ni coste.
- SQLite transacciones https://sqlite.org/lang_transaction.html y FK https://www.sqlite.org/foreignkeys.html: BEGIN IMMEDIATE, rollback y padres antes de hijos; ADAPTAR restauración completa dentro de una transacción y comprobar antes del commit. No desactivar FK dentro de transacción (no tendría efecto).
- Joplin https://joplinapp.org/help/apps/import_export/ preserva metadatos en JEX; documenta un fallo de identidad al reconstruir enlaces ENEX por títulos ambiguos. REFERENCIA de aplicación real: conservar IDs exactos, nunca resolver por nombre ni copiar contenido. Licencia https://github.com/laurent22/joplin/blob/dev/LICENSE AGPL-3.0-or-later salvo excepciones por directorio: no importar código. Documentación activa; no dependencia, cloud ni coste.
Comparación: copia SQLite física vs snapshot semántico versionado. Elegir semántico existente: filtrado explícito, compatibilidad de owners y límites antes de asignación; no agregar librerías. Fallos convertidos en negativas: IDs ambiguos/duplicados, FK ausente, destino ocupado, bytes truncados, revisión/receipt alterados, identidad restaurada stale. No atribuir seguridad FARO a estas fuentes.

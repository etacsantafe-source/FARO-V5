**Conclusión del benchmark**: La referencia principal de P05 por dominio es **Actual Budget** para lectura financiera/historial y filtrado; **Grocy** para transiciones stock/compra/cocina; **KitchenOwl** para experiencia de recetas/plan; **Android offline-first + núcleo V5** para persistencia local y flujos sin IA. No hay solución externa que satisfaga directamente score transversal Radar con cobertura parcial, 6 meses con persistencia ilimitada o AtomicApply V5: \`SIN_CANDIDATO_MATERIAL\` para esos motores, desarrollar contrato propio SOLO cuando corresponda.

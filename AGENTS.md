# Reglas para FARO V5 — repositorio de transición

La IA piensa; FARO ejecuta. Este repositorio permanece PRIVADO y en preparación.

La fuente de verdad de desarrollo sigue siendo el repositorio original y C138 hasta un handoff expresamente aprobado. No introducir una segunda autoridad.

NUNCA publicar el repositorio, encender modo noche, activar V2, abrir S3/S4, ejecutar Actions o alterar permisos por inferencia. Requiere autorización apropiada y gates.

Antes de cualquier trabajo material: comprobar HEAD/branch, writer/epoch, checkpoint, scope, plan aprobado, idempotencia, consentimiento, separación Evidence/Reality y ausencia de escrituras concurrentes. Si falta evidencia: BLOCKED/NO WRITE.

Código producto solo dentro de `v5/`; no V3/V4, credenciales, materiales de firma ni historial antiguo. Pruebas físicas T4 no son reemplazables por JVM/CI.

Leer `docs/MIGRATION_BASELINE.md` y contrastar con el estado durable más reciente en el repositorio original antes de cualquier migración material.
